## Функционал приложения
* Выбор функции – 10 типов функций (линейная, квадратичная, кубическая, синусоида, косинусоида, тангенсоида, экспонента, логарифмическая, модуль, обратная пропорциональность).
* Ввод коэффициентов – динамические поля ввода, отображающиеся только для нужных коэффициентов.
* Построение графика – визуализация функции синей линией на интервале x ∈ [-5; 5].
* Исследование функции – автоматический расчёт (область определения, чётность/нечётность, периодичность, монотонность, экстремумы,
нули функции, область значений, сохранение результатов в текстовый файл)

## Архитектура и проектирование
Функциональная структура ПО спроектирована в Ramus Educational (стандарт IDEF0) и разделена на 4 ключевых блока:
1. **А1:** Ввод и проверка исходных данных
2. **А2:** Выбор алгоритма исследования
3. **А3:** Вычисление характеристик функции
4. **А4:** Формирование и вывод результатов

Основные обработчики и методы, реализованные в коде
* `Button1_Clik` - Обработчик нажатия кнопки "Выберите" на Form1.
* `UpdateUIForFunction` - Настраивает интерфейс Form2: отображает формулу функции и показывает только те поля ввода, которые необходимы для выбранной функции.
* `HideAllFields` - Скрывает все поля ввода коэффициентов, чтобы показать только нужные.
* `ShowField` - Отображает конкретную пару элементов (Label и TextBox) для ввода коэффициента.
* `CalculateY` - Вычисляет значение функции y = f(x) в заданной точке x.
* `btnGraph_Click` - Построение графика, настраивает оси.
* `btnResearch_Click` - Исследует функцию.
* `GetDomain` - Определяет область определения функции.
* `GetParity` - Определяет чётность/нечётность функции.
* `GetPeriodicity` - Определяет периодичность функции.
* `GetMonot` - Определяет монотонность функции.
* `FindExtremums` - Находит экстремумы функции.
* `FindZeros` - Находит нули функции.
* `GetRange` - Определяет область значений функции на интервале [-5,5].

## Развертывание и запуск
Программа является портативной и не требует полноценной установки
1. Перейдите в директорию с собранным проектом (`.../bin/Release/` или `.../bin/Debug/`).
2. Скопируйте исполняемый файл `Исследователь Функций.exe` (и сопутствующие библиотеки, если применимо) на целевой ПК
3. Запустите файл `Исследователь Функций.exe`. Время запуска и восстановления системы после сбоя не превышает 10 секунд

## Тестирование
Приложение успешно прошло несколько этапов ручного тестирования методом «черного ящика»
* **Функциональное тестирование:** подтверждена корректность построения графика, исследования функций, кнопок выхода и сохранения.
* **Тестирование UI:** проверено визуальное отображение элементов формы. Интерфейс выполнен в нейтральной, не перегружающей зрение гамме,
элементы не перекрывают друг друга.
* **Тестирование безопасности/надежности:** программа устойчива к некорректным действиям пользователя и выдает предупреждающие сообщения при ошибочном вводе
